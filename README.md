# CRUD Data Buku - PHP Native MVC

Aplikasi CRUD untuk mengelola data buku menggunakan PHP Native, pola MVC, dan database MySQL.

## Teknologi
- PHP Native
- MySQL/MariaDB dengan PDO
- Git

## Fitur
- Menampilkan data buku
- Menambah data buku
- Mengedit data buku
- Menghapus data buku

## Atribut Buku
ID, judul, penulis, penerbit, tahun terbit, dan kategori.

## Struktur MVC
- `models/` : mengelola data
- `views/` : menampilkan halaman
- `controllers/` : mengatur alur aplikasi
- `config/` : konfigurasi database
- `database/` : file SQL
- `public/` : halaman utama aplikasi
